# Glint for Mac — beta downloads

Mirror your iPhone on your Mac with USB or experimental Wi-Fi.

**[Website](https://glintmirror.eu/) · [Downloads and source](https://github.com/anexbmx/Glint-downloads/releases) · [Installation](https://glintmirror.eu/docs-download) · [Support](https://glintmirror.eu/support)**

This repository hosts release files and release notes. The app's matching source is
provided as versioned release attachments rather than as repository history.

Choose **Intel** for Intel Macs or **Apple Silicon** for Macs with an Apple chip.
Read each release's macOS minimum and beta limitations before installing.

Every public release includes signed/notarized installers, SHA-256 checksums,
matching application source, dependency source archives and license notices.
Original Glint software is **GPL-3.0-or-later**. Artwork is separately scoped;
see LICENSE and LICENSING.md inside the matching source attachment. Third-party
components retain their own licenses.

Wi-Fi and native input are experimental. MCP currently requires USB. This beta
has limited clean-machine and Apple Silicon hardware test coverage.
